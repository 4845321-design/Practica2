# La Palabra Prohibida

## 1. Nombre y frase

**La Palabra Prohibida**

Un juego de a dos en un solo celular: uno describe una palabra sin decir las cinco prohibidas, y el otro tiene que adivinarla antes de que se acabe el tiempo.

## 2. Qué hace y cómo se usa

Una persona describe la palabra de la carta sin decir ninguna de las cinco palabras prohibidas.
La otra persona intenta adivinarla antes de que termine el minuto.
Pulsa «¡Acertó!» si adivina o «Dijo una prohibida» si se menciona una palabra prohibida; gana quien acierta cinco palabras con menos de tres faltas.

## 3. Enlace para abrirlo

[Abrir el repositorio del proyecto en GitHub](https://github.com/4845321-design/Practica2).

El juego no está publicado como sitio web. Para abrirlo en tu máquina, sigue los comandos de la siguiente sección y visita [http://localhost:5173](http://localhost:5173).

## 4. Cómo correrlo en otra máquina

Se necesita tener instalados Git, Node.js y npm. Ejecuta:

```bash
git clone https://github.com/4845321-design/Practica2.git
cd Practica2
npm install
npm run dev
```

Abre la dirección local que indique Vite (normalmente `http://localhost:5173`). Para ejecutar las pruebas o compilar el proyecto:

```bash
npm test
npm run build
```
